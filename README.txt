STUDIO LUMIÈRE — STAGE 1

This ZIP contains replacement files for your fresh React + Vite project.

1. Extract the ZIP.
2. Copy its "src" folder into your studio-lumiere project.
3. Replace the existing src folder when Windows asks.
4. Run:
   npm run dev

Required packages:
- framer-motion
- lucide-react
